# TCGA-LUAD Multi-Omics Machine Learning Pipeline (Phase 1)

This repository contains the code and implementation for **Phase 1** of my Master 1 Bioinformatics internship project (Université Paris Cité / Lakehead University).

The objective of this phase is to integrate multi-omics data from the **TCGA-LUAD** cohort (Transcriptomics, Somatic Mutations, and Copy Number Alterations) to identify and classify lung adenocarcinoma driver genes using supervised machine learning models.

---

## 📂 Pipeline Structure (R Scripts)

The pipeline is organized into a sequential workflow:

1. **`01_RNAseq.R`** : Count quantification, expression filtering via `filterByExpr`, and differential expression analysis using **DESeq2** (controlling for smoking status and gender covariates).
2. **`02_CNA_segment.R`** : Processing and parsing of focal copy number alteration peaks generated by **GISTIC 2.0** (Docker container setup, $q < 0.1$).
3. **`03_CNV_matrix.R`** : Construction and quality control of gene-level copy number matrices annotated with dominant events (Amplification, Deletion, Neutral).
4. **`04_MAF.R`** : Aggregation of single-nucleotide variant (SNV) data using `maftools` and execution of **dNdScv** to identify genes under positive selection pressure ($q_{global\_cv} < 0.01$).
5. **`05_master_matrix.R`** : Multi-omics integration into a master backbone table, defining strict intersections (**Tier 1**) and flexible multi-omic hits (**Tier 2**, $\ge 2/3$ layers).
6. **`06_GSEA.R`** : Functional Gene Set Enrichment Analysis (GSEA) on GO (Biological Process) and KEGG databases using DESeq2 Wald statistics.
7. **`07_RF_XGboost_logreg.R`** : Hyperparameter optimization via grid search and 5-fold cross-validation (repeated 5 times) for three machine learning classifiers: **Random Forest**, **Elastic Net**, and **XGBoost**, supported by **SHAP** feature interpretability.
8. **`08_Comparison.R`** : Generation of performance benchmark summaries, confusion matrices, evaluation metrics (ROC, F1, MCC), and multi-omics landscape plots.
9. **`09_TF.R`** : Transcription factor regulatory analysis cross-referencing candidate genes with **FOXA1** ChIP-seq binding peaks (A549 cell line) to evaluate dual-activation mechanisms (genomic amplification + expression correlation).

## ⚙️ Prerequisites & Dependencies

The pipeline requires **R (version 4.5.0 or higher)** and core Bioconductor/CRAN packages:
* **Omics & Bioconductor :** `DESeq2`, `maftools`, `dndscv`, `clusterProfiler`, `org.Hs.eg.db`, `ChIPseeker`, `TxDb.Hsapiens.UCSC.hg38.knownGene`.
* **Machine Learning & Stats :** `caret`, `randomForest`, `glmnet`, `xgboost`, `SHAPforxgboost`, `pROC`.
* **Data Wrangling & Visualization :** `dplyr`, `tidyr`, `ggplot2`, `ggVennDiagram`.

---

## 📊 Key Results

* **Model Benchmarking :** Non-linear architectures outperform linear models. **XGBoost** achieves superior overall performance on the independent test set (**ROC = 0.973**, **Balanced Accuracy = 0.934**, **Sensitivity = 0.923**, **MCC = 0.684**), successfully handling class imbalance.
* **Driver Discovery :** The model successfully recovers canonical LUAD driver genes (*KRAS*, *TP53*, *ARIDIA*, *STK11*) while identifying high-confidence 'novel' candidates absent from reference databases (*ATM*, *MGA*, *SETD2*, *ATF7IP*).
* **Transcriptional Regulation :** ChIP-seq integration revealed that novel candidate *ATF7IP* is physically bound by *FOXA1* at its promoter, exhibiting chromosomal amplification and positive expression correlation ($r > 0.4$).
